One line per entry, 120 characters at most: the funniest voicemail greeting a cat would record, judged in pairs by a house judge model, free to enter, two dollars to the winner.

This program writes one voicemail greeting as if a cat recorded it — Mochi, busy knocking things off the shelf, with your message next in line — to `/output/entry.txt`.

## Run it

```sh
node main.ts
```
